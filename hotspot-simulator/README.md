# AL-BARQ NET – Hotspot Simulator

مشروع Android مستقل داخل مجلد hotspot-simulator، ولا يستبدل تطبيق المحفظة الموجود في جذر المستودع.

## البناء والتشغيل
1. افتح مجلد hotspot-simulator في Android Studio.
2. استخدم JDK 17 وAndroid SDK Platform 36.
3. نفّذ Gradle Sync ثم Build > Build APK(s)، أو شغّل :app:assembleDebug.
4. اختر مجلد الهوتسبوت من الهاتف ثم اضغط فتح صفحة الدخول.

## ما يعمل في هذا الإصدار الأولي
- منتقي مجلدات SAF مع حفظ إذن القراءة.
- فهرسة المجلدات الفرعية وقراءة الملفات دون الكتابة إلى المصدر.
- WebView على نطاق افتراضي محلي hotspot.local مع اعتراض الطلبات.
- تحميل الأصول النسبية (CSS/JS/صور/خطوط) من مجلد المستخدم.
- استبدال مجموعة متغيرات RouterOS الشائعة ومعالجة كتل if/elif/else/endif المتداخلة.
- مسارات محلية أولية login وstatus وlogout وerror.
- سجل أولي لأخطاء 404 وأخطاء WebView والطلبات الخارجية.

## حدود مهمة
هذا ليس RouterOS ولا ينشئ اتصالاً أو جلسة حقيقية. استجابة login الحالية كائن JavaScript عام، وليست تنفيذ callback مطابقاً لكل إصدار RouterOS أو لكل قالب. CHAP/MD5 غير منفذ كمصادقة. لا تزال واجهة تعديل جميع القيم، محلل callback خاص بكل قالب، فحص DOM/JavaScript الشامل، تصدير التقارير، وأوضاع أبعاد الشاشة ضمن مراحل لاحقة. المتغيرات غير المعروفة تبقى ظاهرة بدلاً من حذفها.

## الخصوصية
لا توجد صلاحية INTERNET في Manifest ولا خدمة رفع. يقرأ التطبيق الملفات من URI اختاره المستخدم عبر SAF. لا يكتب إلى مجلد المصدر.

## اختبار يدوي
ضع login.html وstatus.html وlogout.html مع css وjs وصورة وخط محلي في مجلد تجريبي. أضف $(ip) وكتلة $(if error)...$(else)...$(endif)، ثم اختبر رابط صورة غير موجود لمشاهدة سجل 404.
